# Medical AI Verification System

A Streamlit research prototype for human-assisted review of health information generated by AI.

## Features
- English interface by default, with a Vietnamese language option.
- Initial and final medical/legal disclaimers.
- Search shortcuts for WHO, CDC, and NIH / MedlinePlus.
- Reviewer-entered source details and evidence summary.
- Green / red / yellow evidence-status display.
- Adapted quality-review questions inspired by DISCERN and JAMA benchmarks.
- Downloadable plain-text review summary.

## Important limitations
This is **not** an automated medical fact-checker. It opens official-site search pages but does not automatically fetch or verify source content. A reviewer must inspect the source, enter the evidence, and select the status.

The DISCERN-inspired questions are an incomplete adapted set, not the full validated DISCERN instrument. The JAMA checks are simple presence/absence checks. Scores represent structured reviewer ratings, not the probability that a medical claim is true. The app has not been clinically validated and must not be used for diagnosis or treatment decisions.

## Run locally
1. Install Python 3.10 or later.
2. Open a terminal in this folder.
3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run:

   ```bash
   streamlit run app.py
   ```

5. The app should open in your browser at a local Streamlit address.

## Suggested next research-development stage
For a later automated version, add controlled retrieval from official sources (for example, selected WHO and CDC pages), store source URLs and retrieval dates, retrieve relevant passages, and present citations for a human reviewer. Do not label a claim as medically safe solely because a search result was found.
